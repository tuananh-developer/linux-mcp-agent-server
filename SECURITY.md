# Security policy

This is an academic Linux observability server. Report vulnerabilities privately to the repository owner rather than opening an issue with tokens, log extracts, or secrets. Never include credentials or raw system journal content in reports.

Supported baseline: Ubuntu 24.04 LTS, loopback MCP backend, Caddy HTTPS on the LAN edge, Keycloak OAuth/OIDC, and a non-root systemd service. The first release is read-only and does not expose command execution.
